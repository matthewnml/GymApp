Diet · MyFitnessPal

Unofficial sync — MFP has no public API and now blocks password logins, so we use your browser session cookie. It's stored encrypted and only used to read your diary totals. This is against MFP's terms and can break if they change their site or Cloudflare blocks the server.
How to get your session cookie
  1. On a desktop browser, log in at myfitnesspal.com.
  2. Open DevTools (F12) → Application (Chrome) or Storage (Firefox) → Cookies → https://www.myfitnesspal.com.
  3. Copy the value of __Secure-next-auth.session-token and paste it below.
  4. Set your diary to Public: MFP Settings → Diary Settings → Diary Sharing → Public. Required — sync gets blocked otherwise.
